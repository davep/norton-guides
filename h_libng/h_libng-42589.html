 Ask user if they are sure that they want to quit
──────────────────────────────────────────────────────────────────────────────

 Syntax

        H_QuitSystem( lClear )

 Arguments:

      lClear - If .T., clear screen

 Returns:

      .T. if the user does want to quit
      .F. otherwise

 Description:

      Pops up a menu with two options - Yes and No.  If the user selects
      Yes, .T. is returned
