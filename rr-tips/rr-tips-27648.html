 Sort multi lingual   How to change to sorting order for foreign languages

 It is not common knowledge that the text file RR.srt can be used to change
 the sort and comparison order of R&R.

 Normally (no RR.srt file is used), R&R sorts are not case sensitive and
 all special foreign characters (ë, è, é, etc.) are sorted next to their
 unaccented versions.

 You can change this default behaviour by installing the RR.srt ascii text
 file in the directory of the R&R programs. The RR.srt file is included on
 R&R Disk 1, but default NOT installed. Copy this text file from the disk and
 see the contents. It is well documented.

 If you are using an SRT file to change the way in which R&R sorts and
 compares character data, note that there is a new RR.SRT variable, CHARSET,
 which enables you to specify which IBM Code Page your computer is using.
 The value of this variable determines how R&R handles sorting and
 comparison of the last 128 characters in a font's character set.

 Instructions for using this and other SRT variables are found in the RR.SRT
 file itself.
