 Display the system status of the running R&R copy

 There is an undocumented feature that is used by the technical support
 staff to help diagnose certain types of problems. Pressing Ctrl-Fl at any
 time displays a System Status Window.

 The first item of information inside the System Status Window is the
 product version number. It's important to know which version of R&R you
 are using in case they need to recreate a problem.

 This screen also contains the product serial number(s). A valid serial
 number is required when you call Concentric for technical support.

 The two statistics pertaining to the number of DOS file channels in use
 are relevant when you receive the error message Insufficient DOS file
 buffers. For example, you can receive this error when you attempt to set a
 file relation. R&R can't open another file when the maximum number of open
 files allowed by DOS has been reached.

 The next fields pertain to the amount of memory available for use by the
 current report. This area in memory is called the heap. The heap Size
 tells you the number of bytes of RAM that are available at program start
 up. It is followed by the number of bytes currently available (Free).
