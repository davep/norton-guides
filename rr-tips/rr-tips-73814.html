 Naming conventions for fields

 Calculated fields
    All calculated fields start with a lower case character (d, c, l, n),
    depending on the type of field that is created. No underscores are
    used, I use Upper case to distinct the different elements of the name.

 Total fields
    All total fields start with lower case "t". In principal, total fields
    are numeric. No underscores are used, I use Upper case to distinct the
    different elements of the name.
