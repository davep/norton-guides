 Print blank forms    Making an empty form sheet as layout master

 If you want to make empty 'fill in the blanks' forms based upon a report
 you have designed to printe the results, do the following:

 1. Set your starting and ending page to 1 in print options control
    printing.

 2. Remove all of your data fields from the report layout so that only the
    fixed portion of the form remains.

 Print this single page report and you will have an empty form master.
