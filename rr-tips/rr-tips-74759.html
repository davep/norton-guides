 Naming conventions for libraries

 My rule is to use the name of the .exe file as the name of the R&R report
 library, e.g. in my program SCOPE.exe I use the report library SCOPE.rp1.

 There are functions (libs) available that will give you the full physical
 name of your exe with the .exe itself. EXPAND.lib is such an example.

 If you use a structure like this, finding the right repport library from
 within your application is straight forward.
