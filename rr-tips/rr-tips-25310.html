 How to configure a generic text printer

 I need to be able to identify a generic text printer in RR for DOS. I have
 used the generic text print driver in RR for WINDOWS and I get the behavior
 I want. I have the most current print drivers for DOS, RR5PTR, and do not
 see the equivilent of the windows generic text driver.

 If you run RRSETUP /3 you can select a generic printer driver.

 Note
 You do need the file RRPRINT3.pcf
